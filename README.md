## ✨ Key Architectural Features

- **Interactive System Architecture Visualizer:** Real-time data pulse animations traveling along SVG connection paths modeling:
  - *TicketReserve:* `React UI -> Spring Boot 3 -> Redis (SET NX Lock) -> MySQL 8 (JPA @Version)`
  - *Aegis Telemetry:* `1,000 Trucks/s -> Socket.io -> Redpanda (Kafka) -> MapLibre WebGL`
  - *Pulse-Triage:* `IoT Vitals Stream -> Spring Boot Stream API -> gRPC -> Python FastAPI`
- **Dynamic Role Lens Switcher:** Toggle between *All Engineering*, *Full-Stack Focus*, and *Java & Backend Focus* to dynamically reorder featured projects and highlight corresponding skills.
- **Floating Glassmorphic Navbar & Command Palette (`Ctrl + K`):** Quick project search, role switching, social actions, and split resume downloads with keyboard shortcuts.
- **In-Browser PDF Resume Viewer Modal:** Preview and switch between official Full-Stack and Java Backend developer resumes directly in the browser.
- **Interactive Developer CLI (`dev_cli`):** Floating in-browser shell drawer with interactive terminal commands (`help`, `whoami`, `skills`, `projects`, `resume`, `contact`).
- **Interactive Cybernetic Particle Network:** 60fps HTML5 canvas constellation background that connects nodes and responds to mouse velocity.
- **3D Bento Grid & Scroll-Driven Timeline:** Tilt cards with glowing spotlight borders, infinite dual-direction tech marquees, and vertical scroll-linked progress beams.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm (v9+)

### Installation
```bash
# Clone the repository
git clone https://github.com/ranjitpatil7/Developer-Portfolio.git

# Navigate into project directory
cd Developer-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
